# Personal Website

This repository is for a personal portfolio website hosted with GitHub Pages.

The local website source is in `C:\Personal website`, connected to the `cocoz1yn.github.io` repository. Its
GitHub Pages address is:

```text
https://cocoz1yn.github.io/
```

## Files

- `index.html`: local entry point that opens Work
- `work.html`: selected work with project search and suggestions
- `project-allentown-ndvi.html`: NDVI and vegetation cover in Allentown
- `project-shooting-victim-visualization.html`: Philadelphia shooting-victim data visualization
- `in-progress.html`: projects in development
- `project-data-center-suitability.html`: parcel suitability agent proposal
- `project-philadelphia-health-accessibility.html`: healthcare accessibility proposal
- `archive.html`: compatibility redirect from the retired Index page to Work
- `about.html`: biography, skills, experience, and creative work
- `contact.html`: contact links and CV
- `style.css`: website styling
- `atmosphere.css`: atmospheric palette and static fallback
- `atmosphere-flow.js`: deforming background flow with pointer response and reduced-motion support
- `script.js`: mobile menu and gallery controls
- `project-search.js`: local project matching and accessible search suggestions
- `assets/`: images, CV, and other files
