In progress / Geospatial AI

Data Center Parcel Suitability Agent: An Explainable Web-Based Screening Tool

This project proposes a web-based AI agent that helps users assess potential data center sites through clear, evidence-based spatial analysis. Using Philadelphia as a pilot area, the prototype will let users select a parcel on a map, choose screening factors, and generate a report explaining the parcel's strengths, concerns, and uncertainties.
